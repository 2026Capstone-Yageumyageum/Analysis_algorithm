# 논문 작성 메모

## 연구 문제

야구 투구 영상에서 프로 선수와 사용자의 투구 자세 유사도를 정량적으로 비교하기 위해, 2D 포즈 기반 신체 정규화와 투구 구간 인식 시간축 정렬이 필요한지 검증한다.

## 핵심 주장 후보

- 현재 포즈 추정 모델은 MediaPipe 2D 관절 좌표를 기준으로 한다. 선택 이유는 RTMPose 대비 실험 영상에서 관절 위치가 더 자연스럽고 스켈레톤 추출이 더 안정적이었기 때문이다.
- 공간 정규화는 먼저 키 기준 정규화에서 출발한다.
- 단순 화면 픽셀 좌표 비교는 카메라 시점과 선수 위치 변화에 취약하다.
- 키 기준 정규화는 영상 내 scale 차이를 일부 줄일 수 있지만, 전후 이동과 원근감 변화에는 한계가 있다.
- 투구 동작은 준비 자세부터 팔로스루까지 속도와 길이가 개인마다 다르므로 전체 흐름에 동적 시간 정렬(DTW)을 직접 적용하면 의미 없는 정렬이 발생할 수 있다.
- 구간별로 분할한 뒤 정규화 특징값에 동적 시간 정렬(DTW)을 적용하면 같은 의미의 투구 구간끼리 비교할 수 있다.

## 방법론 문장 후보

본 연구에서는 MediaPipe 2D 관절 좌표를 기반으로 투구 동작을 준비, 다리 들기, 보폭 이동, 릴리즈, 팔로스루 구간으로 구분하고, 각 구간 내에서 골반 중심 상대좌표, 신체 크기 기준 정규화 길이, 관절 각도 특징값을 추출하였다.

이후 각 구간별 특징값 흐름에 동적 시간 정렬(DTW)을 적용하여 사용자와 프로 선수 간 시간축 차이를 완화하였다.

## 실패 실험의 논문적 의미

- RTMPose와 MediaPipe 비교는 MediaPipe를 기준 포즈 추정 모델로 선택한 근거가 된다.
- 키 기준 정규화의 한계는 신체 기준 좌표계 정규화 필요성을 설명한다.
- 전체 동적 시간 정렬(DTW) 실패는 투구 구간 인식 동적 시간 정렬 설계의 필요성을 설명한다.

## PitcherMotion 스타일 실험의 의미

PitcherMotion 스타일 실험은 최종 유사도 점수를 계산하는 단계가 아니라, 비교 가능한 스켈레톤과 특징값을 만드는 중간 표현 실험이다.

이 실험은 다리 들기 시점을 기준으로 두 영상을 맞추고, 관절 각도와 이동량 그래프를 통해 어떤 특징값이 유사도 계산에 유용한지 확인하기 위해 사용했다.

따라서 논문에서는 “유사도 계산을 위한 특징값 추출 및 시각 검증 단계”로 설명할 수 있다.

## 아직 채워야 할 내용

- 최종 특징값 조합
- 유사도 점수 산식
- 실험 데이터셋 설명
- 정량 평가 기준
- 사용자 피드백 또는 전문가 검토 기준
