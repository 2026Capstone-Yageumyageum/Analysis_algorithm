# exp07_phase_direction

## 실험 이름

Phase 시작-끝 방향 벡터 기반 폼 유사도 B 실험

## 목적

프로 선수와 사용자 투구 동작을 phase별로 나눈 뒤, 각 phase의 시작 프레임과 끝 프레임 사이에서 관절이 이동한 방향만 비교한다.

이 실험은 속도, 이동량 크기, phase 내부의 세부 시간 흐름을 의도적으로 줄이고 “이 구간에서 몸이 어느 방향으로 움직였는가”를 1~100 점수로 표현할 수 있는지 확인하기 위한 1차 정량화 실험이다.

## 입력 데이터

- 프로 영상: `/Users/sonjiwoon/capstone/pro_data/hyun_jin_ryu_ball_to_junior_caminero_20230923_6s.mp4`
- 사용자 영상: `/Users/sonjiwoon/capstone/user_data/y1.mp4`
- 결과 경로: `/Users/sonjiwoon/capstone/Analysis_algorithm/outputs/exp6`

## 방법

1. MediaPipe Pose 2D로 관절 좌표를 추출한다.
2. 좌완/우완 방향을 통일한다.
3. 골반 중심 기준 상대좌표와 body-scale 단위로 정규화한다.
4. 투구 동작을 준비 자세, 다리 들기, 보폭 이동 / 팔 준비, 릴리즈, 팔로스루로 나눈다.
5. 각 phase의 시작 프레임과 끝 프레임에서 사용할 관절의 이동 벡터를 계산한다.
6. 이동 벡터를 단위 벡터로 바꿔 이동량 크기 차이를 줄인다.
7. 프로와 사용자 단위 벡터의 코사인 유사도를 1~100 점수로 변환한다.

## Phase별 사용 관절

| Phase | 사용 관절/기준점 |
| --- | --- |
| 준비 자세 | 골반 중심, 어깨 중심 |
| 다리 들기 | 리드 무릎, 리드 발목, 골반 중심, 투구 손목, 투구 팔꿈치 |
| 보폭 이동 / 팔 준비 | 보폭 발, 보폭 무릎, 골반 중심, 투구 손목, 투구 팔꿈치, 투구 어깨 |
| 릴리즈 | 투구 손목, 투구 팔꿈치, 투구 어깨, 어깨 중심, 골반 중심 |
| 팔로스루 | 투구 손목, 투구 팔꿈치, 투구 어깨, 어깨 중심, 골반 중심 |

## 결과 요약

| 항목 | 결과 |
| --- | ---: |
| 전체 후보 점수 | 58.32 |
| 준비 자세 | 43.35 |
| 다리 들기 | 58.48 |
| 보폭 이동 / 팔 준비 | 68.83 |
| 릴리즈 | 36.86 |
| 팔로스루 | 84.07 |

가장 낮은 phase는 릴리즈였고, 가장 낮은 관절/기준점은 릴리즈 구간의 투구 어깨였다.

## 관찰 결과

- 팔로스루는 84.07로 높게 나와 phase 시작-끝 방향 비교가 특정 구간에서는 직관적인 후보 점수를 만들 수 있음을 확인했다.
- 보폭 이동 / 팔 준비 구간은 하체와 골반 이동 방향이 매우 높게 나왔지만, 투구 팔 쪽 점수는 낮게 나왔다.
- 릴리즈는 전체 phase 중 가장 낮았고, 특히 투구 손목, 팔꿈치, 어깨 방향 점수가 낮았다.
- 준비 자세는 움직임 자체가 작아 어깨 중심이 제외되고 골반 중심만 사용되었다.

## 문제점

- 릴리즈 구간이 프로 영상 기준 2프레임으로 잡혀 시작-끝 방향 벡터가 노이즈에 매우 민감하다.
- 시작-끝 방향만 비교하기 때문에 phase 내부에서 팔이 어떻게 돌아가는지, 즉 코킹과 가속 과정의 궤적은 반영하지 못한다.
- 움직임이 작은 관절은 방향 벡터가 불안정해서 제외해야 한다.
- 골반 중심은 body-frame에서 항상 0이 되므로, 별도로 body-scale로 나눈 이미지 좌표 변화량을 사용했다.

## 유사도 알고리즘에 주는 의미

이 실험은 최종 유사도 점수라기보다 “시간 변화량을 최대한 제거한 정량 후보”에 가깝다.

따라서 B 실험은 phase별 방향성 비교의 기준선으로 보관하고, 이후 A 실험에서 phase 내부 프레임별 방향 벡터 흐름을 비교해 릴리즈와 팔 준비 구간의 세부 움직임을 보완하는 것이 필요하다.

## 현재 결정

- B 실험은 1차 정량 후보로 유지한다.
- 최종 유사도 점수로 바로 사용하지는 않는다.
- 릴리즈 phase 정의가 너무 짧게 잡히는 문제를 먼저 개선해야 한다.
- 다음 후보로 A 실험, 즉 phase 내부 방향 변화 흐름 비교를 진행한다.
